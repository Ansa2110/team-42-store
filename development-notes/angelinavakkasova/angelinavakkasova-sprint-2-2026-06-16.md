# Sprint 2 — Routing & Signals

- **What was done:**
  Added and organized all visual assets for the ShopFront project. Created category images, product images, authentication illustrations, About Us page image, banner graphics, favicon, and a custom responsive 404 page. Structured assets inside the `public/assets` directory, connected images to application pages, configured routing for unknown URLs, added a home return button, and integrated Angular Material icons.

- **Problems:**
  There was uncertainty about the correct asset structure, file naming conventions, and how Angular serves files from the `public` directory. The 404 illustration also did not fit the layout correctly, caused unwanted scrolling, and required adjustments for different screen sizes.

- **Solutions:**
  Created a clear folder structure for assets, standardized file names, and updated image paths to use Angular's public asset routing (`/assets/...`). For the 404 page, separate desktop and mobile layouts were created, image sizing was adjusted with Tailwind CSS utilities, page overflow was fixed, and spacing, typography, and alignment were refined to match the design.

- **What I learned:**
  Learned how Angular serves static files from the `public` directory, how to organize project assets for scalability, how to create adaptive layouts with Tailwind CSS, how to manage image scaling across breakpoints, and how to combine Angular Material components with custom responsive UI.

- **Plans:**
  Continue integrating assets into final UI components, improve overall responsiveness, connect authentication to the backend, implement the About Us page, and refine UI consistency across the application.

- **Time spent:**
  4h
